# Praveen Koppad — Professional Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript, suitable for GitHub Pages.

## Deploy

Upload **index.html** and the **assets** folder to the root of `praveenkoppad916-hue.github.io` on the `main` branch. GitHub Pages should be set to **Deploy from a branch → main → /(root)**.

## Included

- Career overview, experience, technical toolkit, education, and contact
- Links to Planetary Rover, Automated Pesticide Sprayer, and SQL Troubleshooting projects
- Resume PDF at `assets/Praveen_Koppad_Resume.pdf`

## Privacy note

Review all career details and the resume before publishing publicly. Do not upload employer confidential documents, customer logs, production credentials, or proprietary code.
